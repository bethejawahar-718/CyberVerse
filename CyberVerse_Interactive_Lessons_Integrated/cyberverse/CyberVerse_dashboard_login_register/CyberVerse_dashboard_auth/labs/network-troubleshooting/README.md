# CyberVerse — Network Troubleshooting Lab

## Files
- `network-troubleshooting.html` — standalone interactive lab
- `css/network-troubleshooting.css` — responsive styles
- `js/labs/network-troubleshooting.js` — simulated diagnostic checks, clues, and answer evaluation

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `network-troubleshooting.html` with Live Server, or open the HTML file directly in a modern browser.

## Lab features
- Four fictional troubleshooting cases.
- Interactive simulated IP, gateway, DNS, and service checks.
- Evidence clues that appear after each check.
- Cause and next-step selection with feedback.
- Score tracking for cases solved during the current page session.
- Reset, clear clues, and next-case controls.

## Integration
Copy the HTML file into your frontend folder, the CSS into your CSS folder, and the JS file into `frontend/js/labs/`. Adjust relative paths if your folder layout differs.

This is an educational simulation only. It does not run actual ping, DNS, port, or network diagnostics on your device.
