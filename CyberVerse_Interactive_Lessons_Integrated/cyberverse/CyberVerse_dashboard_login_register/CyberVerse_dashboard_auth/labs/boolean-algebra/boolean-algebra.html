03 / LAW GUIDE

Common Boolean laws

IdentityA AND 1 = AA OR 0 = A
DominationA AND 0 = 0A OR 1 = 1
IdempotentA AND A = AA OR A = A
ComplementA AND NOT A = 0A OR NOT A = 1
De MorganNOT (A AND B) = NOT A OR NOT BNOT (A OR B) = NOT A AND NOT B
Notation

In Boolean algebra, 1 means TRUE and 0 means FALSE. AND is true only when both inputs are true; OR is true when at least one input is true.
