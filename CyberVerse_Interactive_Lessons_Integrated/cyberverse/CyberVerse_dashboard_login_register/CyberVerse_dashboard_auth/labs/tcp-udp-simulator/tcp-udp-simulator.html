TCP vs UDP

Compare reliable, connection-oriented delivery with lightweight datagrams. Adjust the network conditions and watch the simulated packets move.

↔

TCP

Transmission Control Protocol

RELIABLE
  • Connection setup with a three-way handshake
  • Sequence numbers and acknowledgements
  • Lost segments can be retransmitted
  • Good for web pages, email and file transfers
➤

UDP

User Datagram Protocol

LOW OVERHEAD
  • No connection handshake
  • Datagrams are sent independently
  • No built-in delivery acknowledgement or retry
  • Useful for live media, games and DNS queries
