04 / KEY CONCEPTS

Remember this

01
Automatic configuration

DHCP can provide IP address, subnet mask, gateway, DNS server and lease duration.

02
Lease

An address is leased for a period, rather than being assigned permanently by default.

03
DHCP relay

A relay agent can forward DHCP messages between clients and a server on another subnet.
