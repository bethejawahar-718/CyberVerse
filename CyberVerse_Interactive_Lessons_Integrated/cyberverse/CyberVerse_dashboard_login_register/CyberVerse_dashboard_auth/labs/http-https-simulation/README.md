# CyberVerse NET-11 — HTTP & HTTPS Simulation Lab

## Run
1. Extract the ZIP archive.
2. Open `index.html` in a modern browser.
3. No installation or internet connection is required.

## Features
- Sample HTTP request and response inspector.
- Searchable HTTP status-code explorer.
- Conceptual HTTP vs HTTPS comparison.
- Five-question quiz with explanations.
- Responsive CyberVerse styling.

## Safety and accuracy
This is an educational frontend simulation. Requests and responses are sample data; the lab makes no live web requests. The HTTPS protected-data placeholder is not real encryption and must not be used to protect information.
