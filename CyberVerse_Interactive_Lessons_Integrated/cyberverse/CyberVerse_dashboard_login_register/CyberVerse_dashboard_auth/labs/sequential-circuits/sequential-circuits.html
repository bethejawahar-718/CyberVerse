Sequential Circuits

Unlike combinational circuits, sequential circuits use stored state. Explore a basic SR latch, a clock-triggered D flip-flop, and a 4-bit binary counter.

Simulation note: These are simplified educational software models, not real electronic hardware. The SR latch uses active-high NOR-style behavior; S = 1 and R = 1 is an invalid input combination. The D flip-flop samples D only on a simulated rising clock edge.
