LEARN THE SIGNALS

What should you look for?

↗

Hostname tricks

Check the actual hostname, not just the brand name written somewhere in the URL. Text before an @ may mislead you.

SIGNAL / 01
!

Urgency & login paths

Words like “verify”, “account”, or “secure-login” can be used in phishing links. They are clues, not proof by themselves.

SIGNAL / 02
⌁

Look-alike characters

Punycode hostnames beginning with xn-- can represent internationalized domain names. Inspect unfamiliar domains carefully.

SIGNAL / 03
◇

HTTPS is not a guarantee

HTTPS encrypts the connection, but phishing sites can use HTTPS too. Always verify the domain and the reason for the link.

SIGNAL / 04

DEFENDER CHECKLIST

Never enter passwords, one-time codes, or payment details on a page reached from an unexpected message. When unsure, contact the organization through an independently verified channel.
