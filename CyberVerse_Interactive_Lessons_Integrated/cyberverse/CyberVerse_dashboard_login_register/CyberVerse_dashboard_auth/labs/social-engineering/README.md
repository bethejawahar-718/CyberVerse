# CyberVerse SEC-07 — Social Engineering Awareness Simulator

A standalone interactive learning module that teaches learners to recognize common social engineering tactics and choose safe responses.

## Run it
1. Extract the ZIP.
2. Open this folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No backend, database, account, API key, or installation is required.

## Included
- Six fictional scenarios: unexpected IT support call, social media request, prize message, tailgating, gift-card impersonation, and unknown USB device.
- Warning signs and manipulation-tactic explanations.
- Three or more response choices per scenario.
- Instant feedback, safe-decision score, progress tracking, and restart.
- Responsive dark CyberVerse interface.

## Safety and privacy
This is an awareness simulation only. It does not contact real people, make calls, send messages, access accounts, connect USB devices, collect personal information, or perform real-world actions. All names and situations are fictional.

## Learning outcomes
Learners practise recognizing impersonation, pretexting, baiting, tailgating, urgency, secrecy, authority claims, and requests for sensitive information. The core response is: Stop, Verify, Report.
