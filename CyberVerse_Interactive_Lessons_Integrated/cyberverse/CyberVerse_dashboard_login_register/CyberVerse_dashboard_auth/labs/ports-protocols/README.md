# CyberVerse — Ports & Protocols Simulation Lab (NET-09)

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. No installation, server, database, or internet connection is required.

## Included
- Port/service matching challenge with randomized questions.
- Automatic scoring and per-answer feedback.
- Searchable service table.
- Keyboard-accessible service detail selection.
- Responsive dark CyberVerse styling.
- Educational notes about ports, TCP, UDP, and sockets.

## Scope and safety
This is a frontend-only educational simulation. It does not scan a network, open sockets, or transmit packets. Service port numbers are common defaults; real deployments may use different ports. HTTPS/HTTP3 note: HTTP/3 typically uses QUIC over UDP, commonly port 443.

## Files
- `index.html` — lab page
- `css/style.css` — responsive styling
- `js/lab.js` — challenge and analyzer logic
