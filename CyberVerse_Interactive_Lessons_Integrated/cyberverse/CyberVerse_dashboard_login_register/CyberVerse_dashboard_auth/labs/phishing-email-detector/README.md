# CyberVerse SEC-06 — Phishing Email Detector

A standalone, browser-based learning simulator for recognizing phishing and suspicious email messages.

## Run the project
1. Download and extract the ZIP file.
2. Open the `CyberVerse_SEC06_Phishing_Email_Detector` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code **Live Server** extension and choose **Open with Live Server**.

No installation, database, API key, or backend is required.

## Features
- Six fictional email scenarios.
- Inspect sender name, sender address, recipient, subject, message body, inert link text, and attachment name.
- Investigation checklist for each scenario.
- Classify each message as **Phishing**, **Suspicious**, or **Legitimate**.
- Immediate explanations and safer next steps.
- Score, completion count, progress bar, and restart control.
- Responsive dark CyberVerse cybersecurity interface.

## Safety and privacy
This is an educational simulation only. All messages, names, domains, links, and attachment names are fictional. Displayed links are plain text and are not clickable. The simulator does not connect to an email account, send messages, open links, download or open attachments, collect credentials, or transmit user data.

## Learning outcomes
After completing the activity, learners should be able to:
- Recognize urgency, threats, unexpected payment requests, and requests for sensitive information.
- Inspect sender addresses and avoid trusting display names alone.
- Treat unexpected links and attachments cautiously.
- Verify requests using a known, independent contact channel.
