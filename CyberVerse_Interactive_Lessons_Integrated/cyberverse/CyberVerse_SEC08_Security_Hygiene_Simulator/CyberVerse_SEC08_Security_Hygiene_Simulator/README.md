# CyberVerse SEC-08 — Security Hygiene Simulator

A standalone interactive module for learning and practising everyday cybersecurity hygiene.

## Run the project
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code **Live Server** extension.

No backend, database, API key, or installation is required.

## Features
- Eight-item daily security hygiene checklist.
- Track checked habits and hygiene progress.
- Quick security guide for device, account, data, and browsing protection.
- Four interactive decision-making situations.
- Immediate answer feedback and explanations.
- Quiz progress, score, and restart controls.
- Responsive CyberVerse dark interface.

## Safety and privacy
This is a local educational simulator. It does not inspect your device, change settings, install updates, create backups, access accounts, or transmit personal information. Checklist progress and quiz answers remain in the current browser page session and are not sent to a server.

## Learning outcomes
Learners practise strong unique passwords, multi-factor authentication, trusted software updates, device locking, backups, careful use of networks, safe links and downloads, and protection of personal information.
