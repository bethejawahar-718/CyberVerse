# CyberVerse — Routing Fundamentals Lab

A standalone educational frontend lab that visualizes basic routing concepts.

## Files
- `routing-fundamentals.html` — lab page and UI
- `css/routing-fundamentals.css` — responsive dark CyberVerse theme
- `js/labs/routing-fundamentals.js` — route tracing and quick-check interactions

## Run it
1. Extract the ZIP.
2. Open `routing-fundamentals.html` in a modern browser.
3. Select a source and destination, then click **Trace packet**.
4. Try the quick-check question at the bottom.

## Learning goals
- Recognize end devices and routers in a small topology.
- Trace a packet across multiple router hops.
- Read a sample routing table and understand next-hop selection.
- Check understanding with a short interactive question.

## Notes
- This is a simplified simulation with example IP addresses and routes.
- It does not send real network packets or configure real routers.
- The page uses Google Fonts when an internet connection is available; system fonts remain as fallback.
