Firewall fundamentals

LEARNING MODE
▣

What is a firewall?

A firewall is a security control that monitors network traffic and applies rules to allow or block connections.

⇄

Inbound & outbound

Inbound traffic comes into a device or network. Outbound traffic leaves it.

⚙

Rules & filtering

Rules can consider direction, source, destination, protocol and port. A matching rule determines the action.

⌂

Host vs network

A host firewall protects an individual device. A network firewall helps control traffic between networks.

⊘

Default deny

With a default-deny approach, traffic is blocked unless a rule explicitly permits it.

≡

Rule order & logs

Some firewalls evaluate rules in order. Logs help administrators review allowed and blocked events.

Remember: A port identifies a service endpoint; TCP and UDP are transport protocols. For example, HTTPS commonly uses TCP port 443.
