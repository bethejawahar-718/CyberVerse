# CyberVerse — Password Security Simulator (SEC-04)

A standalone, beginner-friendly password-strength learning lab built with:
- HTML5
- CSS3
- Vanilla JavaScript

## Run it
1. Extract `password-security-simulator.zip`.
2. Open the extracted `password-security-simulator` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Type a made-up sample password to see the estimate and checklist update.

## Files
- `index.html` — simulator page and accessible controls
- `css/password-security.css` — responsive CyberVerse styling
- `js/password-security.js` — local password checks and feedback

## Privacy and limitations
- Password analysis runs locally in your browser.
- This project does not send the entered value to a server, write it to local storage, or save it.
- Use fictional examples only. Do not enter a password you use for a real account.
- The strength result is an educational heuristic, not a real cracking-time prediction or security guarantee.
- This is the frontend lab only; it is not connected to a database or login system.

The Google Fonts import is optional. If the device is offline, the page falls back to locally available fonts.
