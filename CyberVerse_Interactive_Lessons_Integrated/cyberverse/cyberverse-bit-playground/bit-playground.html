02 / UNDERSTAND

How place values work

In an 8-bit unsigned number, each position is a power of two. The decimal value is the sum of the place values whose bits are set to 1.

03 / KEY IDEAS

Remember

  • Bit: one binary digit, either 0 or 1.
  • Byte: 8 bits.
  • Range: an unsigned byte represents values from 0 to 255.
  • Hex: two hexadecimal digits can represent one byte (00–FF).
