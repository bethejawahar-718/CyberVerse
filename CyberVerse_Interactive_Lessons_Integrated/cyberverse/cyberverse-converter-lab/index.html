QUICK GUIDE

Understand the bases

01

Binary

Base 2 uses only 0 and 1. Computers use bits to represent data.

Example: 101010₂ = 42₁₀

08

Octal

Base 8 uses digits from 0 through 7.

Example: 52₈ = 42₁₀

10

Decimal

Base 10 is the everyday number system, using digits from 0 through 9.

Example: 42₁₀

16

Hexadecimal

Base 16 uses 0–9 and A–F, where A = 10 through F = 15.

Example: 2A₁₆ = 42₁₀
